# Sanjay — Static Portfolio

A responsive static portfolio made with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Set Framework Preset to **Other**.
5. Leave Build Command and Output Directory empty/default; no build step is needed.
6. Deploy.

## Personalize before publishing
- Check `assets/profile.jpg` and replace it if you prefer another portrait.
- Verify the email address and education details in `index.html`.
- Add your actual GitHub and LinkedIn profile links when ready.
- Add project source-code/demo links when you publish those projects.
- Add your CV PDF to `assets/` and add a download link if desired.

This is a static frontend only. It has no backend, database, or API.
